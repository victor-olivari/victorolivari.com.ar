# victorolivari.com.ar

Sitio personal de Víctor Olivari, corredor inmobiliario y abogado en Resistencia,
Chaco. Presenta sus tres áreas de trabajo (Bienes Raíces y Tasaciones, Servicios
jurídicos y Capacitaciones), su trayectoria y los canales de contacto de cada una.

Sitio en línea: https://www.victorolivari.com.ar

## Cómo se publica

Este repositorio contiene el sitio tal como se publica. Cada carpeta es una
dirección (`/bienes-raices/`, `/contacto/`, …) y se edita directamente en su
`index.html`. Al subir un cambio, GitHub Pages lo publica sobre el dominio propio
declarado en `CNAME`.
